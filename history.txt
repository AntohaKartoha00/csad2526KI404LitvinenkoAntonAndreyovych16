1. Створи main.cpp з мінімальною програмою "Hello World"
2. Згенеруй базовий CMakeLists.txt для main.cpp
3. Запусти CMakeLists.txt щоб на виході я отримав exe файл який ти також маєш запустити щоб на екран вивелось Hello World
4. Створи два файли: math_operations.h і math_operations.cpp. У файлі
math_operations.h оголоси функцію int add(int a, int b); з коментарем, що це
проста функція для додавання двох чисел. У файлі math_operations.cpp реалізуй
цю функцію
5. Створи каталог tests. У ньому потрібно створити файл unit_tests.cpp. В цьому
файлі мають бути юніт тести для файлу з math_operations.h ,
використовуючи Google Test. Створи кілька тестів: Додавання двох
позитивних чисел. Додавання від’ємних чисел. Додавання нуля. Додавання
великого числа. Файл має містити основну функцію main() для запуску тестів.
6. Онови CMakeLists.txt: підключи Threads, спробуй знайти Google Test, а якщо не
знайдеш — підтягни через FetchContent з тегом v1.14.0. Створи статичну
бібліотеку math_operations, виконуваний файл test_app із main.cpp, тестовий
таргет unit_tests і зареєструй тест через enable_testing() та add_test(); додай
ціль run_tests, яка викликає ctest -C $<CONFIG> --output-on-failure
5. Сконфігуруй CMake-проєкт із Google Test: винеси логіку з
math_operations.cpp/.h у бібліотеку, додай залежність unit_tests від
GTest::gtest, GTest::gtest_main і Threads::Threads, забезпеч FetchContent для
googletest (v1.14.0) якщо пакета немає, підключи поля include та створи ціль
run_tests, що будує й запускає ctest для unit_tests.
6.Створи bash-скрипт ci.sh для локального білдування C++ проєкту з
використанням CMake. Скрипт має: Створювати каталог build, якщо він не
існує. Переходити в цей каталог. Виконувати команду cmake .. для
конфігурації. Виконувати cmake --build . для збірки. Запускати тести через
ctest. Працювати без параметрів. Виводити повідомлення про успішний або
неуспішний білд.
7. Створи Windows batch-скрипт ci.bat для локального білдування C++ проєкту
з використанням CMake. Скрипт має: Створювати каталог build, якщо його
немає. Переходити в каталог build. Виконувати cmake .. для конфігурації.
Виконувати cmake --build . для білду. Запускати тести через ctest. Виводити
повідомлення SUCCESS або FAILED після виконання.
