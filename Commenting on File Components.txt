 Модуль: baud_gen.v
 Призначення: Генератор бодової швидкості з оверсемплінгом
 Опис:
   Цей модуль генерує одиничний імпульс 'tick' з частотою, що дорівнює
   (BAUD_RATE * OVERSAMPLE_FACTOR). Він використовується для синхронізації
   роботи передавача (uart_tx) та приймача (uart_rx).
   На кожен біт UART-послідовності припадає OVERSAMPLE тиків.

 Параметри:
   CLOCK_FREQ - частота системного такту (Гц)
   BAUD       - цільова швидкість UART (бод)
   OVERSAMPLE - коефіцієнт оверсемплінгу (зазвичай 16)

 Порти:
   clk   - вхід системного такту
   rst_n - асинхронний скид (активний рівень 0)
   tick  - вихідний імпульс тривалістю один такт (активний рівень 1)

 Внутрішні регістри:
   counter - лічильник тактів для генерації тику

 Формула розрахунку:
   CLKS_PER_TICK = CLOCK_FREQ / (BAUD * OVERSAMPLE)
   Приклад: 50 МГц / (115200 * 16) ≈ 27 тактів на один тик

 Модуль: uart_tx.v
 Призначення: Передавач UART (формат 8N1)
 Опис:
   Модуль реалізує передавач асинхронного послідовного інтерфейсу UART
   з форматом 8 біт даних, без парності, 1 стоп-біт (8N1).
   Використовує оверсемплінг для точної синхронізації бітів.
   Дані передаються LSB-first.

 Параметри:
   OVERSAMPLE - кількість тиків на один біт (зазвичай 16)

 Порти:
   clk     - системний такт
   rst_n   - асинхронний скид (активний 0)
   tick    - імпульс синхронізації від baud_gen
   i_data  - вхідні дані для передачі (8 біт)
   i_send  - сигнал запуску передачі (активний 1)
   o_tx    - вихідна послідовна лінія UART (стан спокою = 1)
   o_busy  - сигнал зайнятості передавача (1 = передача в процесі)
   o_done  - імпульс завершення передачі (тривалість 1 такт)

 Внутрішні регістри:
   state          - стан автомата керування (FSM)
   oversample_cnt - лічильник для відліку тривалості біта
   bit_index      - індекс поточного біта даних (0-7)
   shift_reg      - регістр зсуву для послідовної передачі

 Стани автомата (FSM):
   TX_IDLE  - очікування команди передачі
   TX_START - передача старт-біта (0)
   TX_DATA  - передача 8 біт даних
   TX_STOP  - передача стоп-біта (1)

 Модуль: uart_rx.v
 Призначення: Приймач UART з оверсемплінгом
 Опис:
   Модуль реалізує приймач асинхронного послідовного інтерфейсу UART
   з форматом 8N1. Використовує подвійну синхронізацію вхідного сигналу
   для запобігання метастабільності та оверсемплінг для точної вибірки бітів.
   Дані приймаються LSB-first.

 Параметри:
   OVERSAMPLE - кількість тиків на один біт (зазвичай 16)

 Порти:
   clk           - системний такт
   rst_n         - асинхронний скид (активний 0)
   tick          - імпульс синхронізації від baud_gen
   i_rx          - вхідна послідовна лінія UART
   o_data        - прийняті дані (8 біт)
   o_data_ready  - сигнал готовності даних (імпульс 1 такт)
   o_frame_err   - сигнал помилки кадру (якщо стоп-біт = 0)

 Внутрішні регістри:
   state          - стан автомата керування (FSM)
  oversample_cnt - лічильник для відліку тривалості біта
   bit_index      - індекс поточного біта даних (0-7)
   shift_reg      - регістр зсуву для накопичення даних
   rx_sync_0, rx_sync - регістри подвійної синхронізації

Стани автомата (FSM):
   RX_IDLE  - очікування старт-біта
   RX_START - перевірка та підтвердження старт-біта
   RX_DATA  - прийом 8 біт даних
   RX_STOP  - прийом та перевірка стоп-біта
